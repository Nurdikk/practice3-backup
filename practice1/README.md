# Практическая работа №3

Емберді Нұрдәулет Ерболұлы. Вариант 11.

Автоматизация резервного копирования и проверка восстановления данных.
Python 3.12 или новее; сторонние библиотеки не нужны.

## Файлы

- `make_test_data.py` — создаёт 18 CSV: buh, kadry, it, по 6 файлов из 200 строк.
- `backup.py` — полные архивы TAR.GZ, SHA-256, ротация до 5 копий, проверка и восстановление.
- `settings.json` — параметры варианта 11.
- `choose_variant.py` — настройки и расчёт выбранного варианта; запускать до генерации данных.
- `run_experiments.py` — воспроизводит задания 1–4 в чистой папке проекта, журнал сохраняет в `experiments.txt`.
- `rpo_rto.md` — расчёт задания 5.
- `experiments.txt` — фактический журнал выполненного эксперимента.

## Быстрый запуск

Откройте терминал в папке practice1:

```powershell
python make_test_data.py
python backup.py
python backup.py verify
python backup.py restore
```

`restore` заменяет учебную папку company_data содержимым выбранной копии.
По умолчанию проверяется или восстанавливается последний архив. Выбрать другой:

```powershell
python backup.py verify backups/backup_ДАТА_ВРЕМЯ.tar.gz
python backup.py restore backups/backup_ДАТА_ВРЕМЯ.tar.gz
```

Для полного эксперимента в чистой распакованной папке вместо команд выше:

```powershell
python run_experiments.py
```

Скрипт создаст данные и 8 копий с интервалом 2 секунды, оставит 5, проверит
повреждённые копии во временной папке и восстановит удалённый учебный отдел buh.
Повторный запуск эксперимента в той же папке блокируется, чтобы не смешивать результаты.
Для повторения распакуйте исходный ZIP в новую папку.

## Пример фактического вывода

```text
Исходные файлы: 58474 байт; архив: 15132 байт; коэффициент сжатия: 3.86
Осталось архивов: 5; хеши файлов между копиями одинаковы
[ЛИШНИЙ] buh/report_2.csv
[ИЗМЕНЁН] buh/report_1.csv
[FAIL] Архив повреждён: контрольная сумма не совпадает
[OK] Данные восстановлены; время с проверкой: 0.178188 с
[OK] Отдел buh вернулся; все исходные файлы совпадают по SHA-256
```

Сообщения FAIL в экспериментах с повреждением ожидаемы. Время и размеры на другом
компьютере могут отличаться. Ротация выполняется после успешной проверки новой копии.

## GitHub

Создайте репозиторий, загрузите содержимое этой папки, включая .gitignore,
и прикрепите ссылку к отчёту. company_data, backups и __pycache__ не загружайте.
В ZIP для публикации они уже исключены. Не загружайте в публичный репозиторий
настоящие данные организации.
